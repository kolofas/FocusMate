# FocusMate — Concept

## Концепция
FocusMate — это персональный инструмент для управления задачами и идеями в стиле "второго мозга".  
Он помогает быстро зафиксировать входящую информацию (inbox) и превратить её в структурированные задачи, которые можно планировать и выполнять.

## Цели
- Снизить хаос во входящей информации (сообщения, идеи, заметки).  
- Упростить процесс превращения "сырых" заметок в конкретные задачи.  
- Обеспечить минимальный, но удобный набор функций для личного productivity.  
- Сделать приложение лёгким и расширяемым (под интеграции с Telegram, календарём и др.).

## Какие проблемы решает
- Сложность структурировать входящие идеи и дела → **Inbox позволяет быстро зафиксировать, не думая о формате.**  
- Потеря заметок в чатиках, блокнотах и ToDo-листах → **централизация.**  
- Множество инструментов перегружено функциональностью → **мы начинаем с простого ядра (Inbox + Tasks).**  

## Преимущества приложения
- Быстрое добавление задач (например, через Telegram).  
- Автоматический парсинг текста (сроки, теги).  
- Минимальный friction: **Inbox → Task → Done.**  
- Архитектура MVP, готовая к масштабированию (боты, интеграции, web).  
- Простая, прозрачная логика (CRUD + Inbox обработка).  

## Визия
FocusMate = "один вход для всех идей" + "минимальные усилия для превращения их в результат".  
Мы делаем инструмент, который не отвлекает, а помогает **работать с фокусом**.

## User Flow

### 1. Добавление задачи (Inbox)
- Пользователь пишет заметку:  
  - в Telegram-бот → "Купить подарок завтра до 18:00 #важно"  
  - в web-форме / API  
- Система парсит текст:  
  - Title: "Купить подарок"  
  - Deadline: завтра, 18:00  
  - Tags: ["важно"]  
- Задача попадает в статус `inbox`.

---

### 2. Обработка Inbox
- Пользователь открывает список Inbox.  
- Может:
  - Уточнить описание.  
  - Поменять статус → `planned`.  
  - Удалить ненужное.  

---

### 3. Работа с задачами
- В списке `planned` пользователь видит отфильтрованные задачи.  
- Может:
  - Сортировать по дедлайну/тегам.  
  - Изменить статус → `done`.  
  - Отложить/редактировать.  

---

### 4. Завершение
- Задача переводится в `done`.  
- (Опционально) статистика: сколько закрыто сегодня/неделю/месяц.  

---

### Ключевая идея
> **У пользователя всегда один вход (Inbox)**,  
> а дальше — минимальные шаги для превращения входящей информации в результат.
