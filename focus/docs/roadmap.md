## MVP Roadmap

### Этап 1 — Базовый каркас
- [x] CRUD для задач.  
- [x] Inbox-поток (приём заметок, парсинг тегов/дат).  
- [ ] Telegram-бот для добавления задач.  
- [ ] Система статусов: `inbox → planned → done`.  

### Этап 2 — Умное планирование
- [ ] Напоминания и дедлайны.  
- [ ] Теги и фильтры.  
- [ ] Очередь задач (приоритеты).  
- [ ] Возможность связать задачи в группы (проекты).  

### Этап 3 — Расширение и интеграции
- [ ] Веб-интерфейс (FastAPI + React/Vue).  
- [ ] Экспорт/импорт (CSV/Notion/Todoist).  
- [ ] Интеграции: Google Calendar, Slack, Email.  
- [ ] Аналитика и статистика (сколько задач выполнено, скорость закрытия).
